Zepto Order Tracking Policy

Category: Order Status and Tracking

1. Checking Order Status

- Customers should open the order or order history section in the Zepto app to view available tracking information.
- The tracking page may display the current order status and available delivery updates.
- Customers should use the latest information shown in the app.
- The chatbot must not invent order statuses or claim to have accessed live tracking unless connected to a verified order system.

2. Order Status Definitions

The following are general example descriptions. Actual status labels may differ in the app.

- Order placed: The order request has been received.
- Confirmed: The order has been accepted for processing.
- Preparing: Items are being collected or prepared.
- Out for delivery: The order has been handed over for delivery.
- Delivered: The order is marked as delivered.
- Cancelled: The order has been cancelled.

The chatbot should explain a status only when it is available from the order system or provided by the customer.

3. Tracking Not Updating

- If tracking information does not change, customers should refresh the app and check again.
- If the status remains unchanged or the estimated delivery time has passed, customers should contact support.
- The chatbot must not promise a specific arrival time without verified tracking information.

4. Order ID

- Customers may be asked to provide their order ID when contacting support.
- The order ID helps support identify the relevant order.
- Customers should avoid sharing passwords, payment PINs, or other sensitive authentication details.

5. Marked Delivered but Not Received

- Customers should check the delivery location and any available delivery instructions.
- If the order cannot be located, they should contact customer support with the order ID.
- Support should investigate the delivery status.
- The chatbot must not claim that a refund or replacement has been approved without confirmation.

6. Chatbot Guidelines

1. Clearly distinguish general tracking instructions from live order information.
2. Never fabricate order status, delivery location, or delivery time.
3. Request an order ID only when necessary for an order-specific issue.
4. Direct unresolved tracking issues to the official support channel.
5. Protect customer privacy and do not request passwords or payment credentials.
